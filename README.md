# 🎮 BattleArena - E-Sports Tournament Management Website

![BattleArena Banner](https://images.unsplash.com/photo-1542751371-adc38448a05e?auto=format&fit=crop&w=1950&q=80)

**BattleArena** एक आधुनिक, गेमिंग-थीम पर आधारित वेब प्लेटफ़ॉर्म है, जिसे ई-स्पोर्ट्स टूर्नामेंट (E-Sports Tournaments) को मैनेज और ट्रैक करने के लिए डिज़ाइन किया गया है। यह पूरी तरह से रिस्पॉन्सिव (Responsive) है और इसमें गेमर्स के लिए एक बेहतरीन डार्क नियन यूज़र इंटरफ़ेस (UI) दिया गया है।

---

## ✨ मुख्य विशेषताएं (Key Features)

* **Neon Gaming UI:** आधुनिक 'Orbitron' और 'Rajdhani' गूगल फॉन्ट्स के साथ आकर्षित रेड और डार्क नियन थीम।
* **Smooth Animations:** बेहतर यूज़र एक्सपीरियंस के लिए स्मूथ स्क्रॉलिंग और फेड-इन पेज ट्रांजिशन (CSS Animations)।
* **Responsive Navigation:** डेस्कटॉप के लिए क्लीन नेविगेशन बार और मोबाइल के लिए पूरी तरह फंक्शनल **Hamburger Menu**।
* **Dynamic Content Loading:** बिना पेज रीलोड किए होम पेज और टूर्नामेंट पेज के बीच स्विच करने की व्यवस्था।
* **Tournament Filters:** गेम्स और कैटेगरी के हिसाब से टूर्नामेंट्स को शॉर्ट/फ़िल्टर करने के लिए स्टाइलिश बटन्स।

---

## 🛠️ उपयोग की गई तकनीकें (Technologies Used)

* **HTML5:** वेबसाइट के स्ट्रक्चर और लेआउट के लिए।
* **CSS3 (Custom Properties):** नियन कलर्स, ग्रिड (Grid), फ्लेक्सबॉक्स (Flexbox), और कस्टम स्क्रॉलबार के लिए।
* **Google Fonts:** प्रीमियम गेमिंग लुक के लिए `Orbitron` और `Rajdhani` फोंट्स।

## 🚀 इस प्रोजेक्ट को अपने कंप्यूटर पर कैसे चलाएं?

**1. रिपॉजिटरी को क्लोन करें (Clone the Repository):**
```bash
git clone https://github.com
```

**2. प्रोजेक्ट फ़ोल्डर में जाएं:**
```bash
cd Battle-Arena
```

**3. वेबसाइट को चलाएं:**
* सीधे `battlearena_website.html` फ़ाइल पर डबल-क्लिक करें, या
* VS Code में खोलकर **Live Server** एक्सटेंशन का उपयोग करके इसे चलाएं।
